# Third-party resources

Local static assets are shipped for offline editing and preview. Exact file hashes and download provenance are recorded in `app/static/vendor/manifest.json`.

- Bootstrap 5.3.8 — MIT; local license: `app/static/vendor/bootstrap/LICENSE`.
- Quill 2.0.3 — BSD-3-Clause; local license: `app/static/vendor/quill/LICENSE`.
- Bootstrap Icons 1.13.2 — MIT; local license: `app/static/vendor/bootstrap-icons/LICENSE`.

Python package licenses remain owned by their respective authors; versions are pinned in `requirements.lock.txt` / `requirements-dev.lock.txt`. Test SMTP credentials and example.com contacts are fictional and are not live credentials.

Email icons and book/document decoration in `app/static/email` are code-authored project SVGs with PNG renders, generated by `scripts/build_email_assets.py`. They are not copied/cropped from the reference screenshot and add no runtime third-party image dependency.
