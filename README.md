# 课信 · 本地作业邮件提醒助手

一个面向助教的中文本地 Web 应用：切换 SMTP 邮箱、保存班级名单、编辑富文本通知、预览与试发，再逐人群发并核查结果。

技术：FastAPI、SQLAlchemy / SQLite、Jinja2、Bootstrap 5、Quill 2。无需 Node 构建；静态依赖已随项目提供。

以下所有命令均在项目根目录（本 README 所在目录）执行。

## 1. 快速启动（Windows / PowerShell）

启动应用：

```powershell
& '.\run.ps1' -OpenBrowser
```

默认仅监听本机 `127.0.0.1:8000`。首次在运行服务的电脑上打开 `http://127.0.0.1:8000`，设置至少 12 个字符的管理员密码。项目会创建独立 `.venv` 并安装锁定依赖，不修改 Conda 基础环境。首次安装需要联网。

若系统禁止运行脚本，可只对这次进程放行，不修改系统策略：

```powershell
& 'C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe' -NoProfile -ExecutionPolicy Bypass -File '.\run.ps1' -OpenBrowser
```

指定其他端口：

```powershell
& '.\run.ps1' -Port 8010 -OpenBrowser
```

仅准备环境而不启动：

```powershell
& '.\run.ps1' -InstallOnly
```

需要 Python 3.11 或更新版本。启动脚本优先使用现场已验证的 `D:\ProgramData\anaconda3\python.exe` 创建虚拟环境，找不到时尝试 Windows Python Launcher。不要使用 `--reload` 或多 worker 运行实际发送任务；同一数据目录的文件锁会拒绝第二个实例。

## 2. 同局域网手机访问

```powershell
& '.\run.ps1' -Lan -Port 8000
```

1. 先从电脑本机完成首次管理员密码设置。
2. 手机和电脑连接同一个可信私人网络，手机打开启动输出中的电脑局域网 IP 地址。
3. 使用相同管理员密码登录。手机无需安装程序。
4. 如防火墙阻止访问，由你自行决定是否仅为“专用网络”允许该端口；应用不会修改防火墙。

**重要：HTTP 不加密网页传输。管理员密码、名单及新输入的 SMTP 授权码可能被同网段攻击者观察。不要用于校园公共 Wi-Fi，不做公网端口映射，建议在电脑本机配置 SMTP 凭据。SMTP 到邮箱服务器的连接仍使用证书校验的 TLS。**

电脑关机、休眠或服务停止后，发送不会继续。按 Ctrl+C 停止；所有已经开始提交的邮件需要先完成或超时（最多为当前任务的并发路数），关闭可能需要等待。重启后不会自动续发旧任务。

## 3. 建议的第一次使用流程

1. **邮箱设置**：添加 QQ、Gmail 或自定义 SMTP。保存后先“测试连接”。这只测试连接、TLS 和认证，不发送邮件。
2. **班级名单**：创建班级，粘贴名单或上传 CSV / XLSX，检查预览，再确认导入。
3. **写通知**：选择发件邮箱、模板，填写课程、作业、北京时间截止时间和提交邮箱。
4. 选择班级、全班或部分学生；切换预览收件人查看姓名替换效果。
5. 点击“发送测试”，仅向你指定的测试邮箱发送一封；在实际邮箱中检查显示。
6. 点击“确认并发送”，核对发件邮箱、主题、完整名单、样例、并发数和每路间隔，勾选确认后才创建群发任务。
7. 在**发送记录**中查看逐人结果；保持电脑及服务运行。页面关闭或退出登录不会主动取消后台任务。

### SMTP 配置

- QQ：`smtp.qq.com`，端口 `465`，隐式 TLS。先在邮箱设置中开启 SMTP 并获取授权码。
- Gmail：`smtp.gmail.com`，端口 `587`，STARTTLS。开启两步验证后创建应用专用密码；学校或组织账号可能禁用该功能。本版不支持 Google OAuth。
- 自定义：输入服务商实际提供的 SMTP 地址、端口、用户名和加密方式。只支持隐式 TLS 或 STARTTLS；不会自动降级到明文或跳过证书校验。
- 发件邮箱通常应与认证账号一致。自定义别名是否允许由邮件服务商决定。
- 编辑时授权码留空表示保持原值，不会回显旧授权码。

### 名单导入

支持以下粘贴格式，每行一位：

```text
张同学 zhang@example.com
李同学,li@example.com
王同学 <wang@example.com>
John Smith john@example.com
```

CSV 支持 UTF-8 / UTF-8 BOM / GB18030；XLSX 读取第一个工作表。支持“姓名/名字/name”与“邮箱/电子邮箱/email”等表头。不识别时手动选择列与“第一行为表头”，重新预览。

- 一次最多 5 MB、5000 行、100 列；不是大规模营销邮件平台。
- 重复邮箱跳过；非法邮箱和姓名冲突逐行展示，不会静默丢弃。
- 有错误时默认阻止确认；你可以明确选择“仅导入有效行”。
- 勾选“覆盖班级中同邮箱、不同姓名”才更新已有姓名；文件内部的姓名冲突需修正或跳过。
- 每个任务只选一个班级，可选部分同学；发送前再次按邮箱去重。
- 示例位于 `.\examples`，全部使用虚构姓名和 `example.com` 地址，不会自动导入或发送。

### 草稿、模板与变量

草稿可保存未完成内容；模板用于复用主题、邮件标题和正文。点击“编辑”模板后，在写通知页面修改，再“保存模板更改”；可覆盖或另存一份。

可插入变量：`{{name}}` 姓名、`{{class_name}}` 班级、`{{course}}` 课程、`{{assignment}}` 作业、`{{deadline}}` 截止时间、`{{submission_email}}` 提交邮箱。

通过变量按钮插入完整变量；不要在一个变量中间混用多种富文本格式。未知变量、格式错误、缺少必填数据、不安全链接、图片或嵌入内容会阻止发送。邮件使用独立 HTML / 纯文本两种 MIME 部分；不同客户端的圆角、间距等可能略有差异，不承诺像素一致。邮件中的“发送作业邮件”按钮使用 mailto 打开默认邮件客户端，同时显示可复制的提交邮箱地址；没有默认客户端时，可自行打开常用邮箱发送。提交邮箱可与 SMTP 发件邮箱不同。旧草稿中的网页链接不会自动当成邮箱，打开后需补填；旧发送任务快照保留原始目标，不被本次改动重写。

## 4. 如何理解发送状态

- **排队中 / 发送中 / 待发送**：尚未完成提交。一人一封，默认 1 路、每路完成后间隔 3 秒；并发可调 1–5 路，间隔可调 1–60 秒。不同任务仍排队。
- **已提交**：SMTP 服务器已接受；不等于进入收件箱、已读或不会退信。
- **明确失败**：确定未提交或被服务器明确拒绝，可人工创建失败项重试任务。
- **结果待确认**：DATA 提交阶段断线或应用在提交时中断，可能已经投递。不会自动重试，避免重复提醒；需人工核查。
- **已暂停**：认证、配额或连接等全局问题，停止继续发送，不自动切换邮箱。
- **已中断**：应用重启或停止，旧任务不自动续发。
- **已取消**：尚未发送的项目被取消；已经提交的邮件无法撤回。

“重试明确失败项”只创建包含 `failed` 项目的新任务，不包含已提交、待确认、已取消和仍未发送项目。对于中断或暂停后的未发送同学，可对照逐人结果，在新通知中重新勾选；不要无差别重发全班。

发送任务冻结当时的正文、收件人及非敏感 SMTP 参数。正在排队或发送的邮箱不能修改或删除。发送有幂等键和单工作线程，但 SMTP 协议无法提供“绝对恰好一次”投递保证，因此对不确定结果采用保守人工核查。

## 5. 数据、安全与备份

- 默认数据库：`%LOCALAPPDATA%\HomeworkReminder\app.db`。
- 可用 `HMR_DATA_DIR` 环境变量指定其他数据目录；一个目录只允许运行一个实例。
- SMTP 授权码：Windows Credential Locker，服务名 `HomeworkReminder.SMTP`。数据库只存引用；凭据库失败时不回退到明文文件。
- 管理员密码：Argon2 哈希；会话为服务端记录，Cookie 为 HttpOnly / SameSite=Strict，8 小时过期。具备 CSRF、来源检查和登录限速。
- 名单、正文、主题、非敏感邮箱参数及发送记录存于 SQLite，**数据库本身不是加密保险箱**。请保护 Windows 账户和磁盘权限。
- 不记录 SMTP 调试协议、授权码或正文。源码忽略数据库、日志、虚拟环境及测试输出。
- 备份前先正常停止服务，再复制整个数据目录。Windows 凭据不随 SQLite 复制而迁移；换电脑或 Windows 用户后需重新填写各邮箱授权码。
- 不存在默认密码；不会安装证书、开放防火墙、添加计划任务或自动向真实学生发信。

忘记管理员密码：停止服务后，在电脑本机运行以下交互命令（密码不会出现在命令行或参数中）：

```powershell
& '.\.venv\Scripts\python.exe' '.\scripts\reset_password.py'
```

只重置管理员密码并使旧会话退出，不修改班级、通知和 SMTP 凭据。

## 9. 班级名单工作区（2026-10-18）

- 桌面窗口至少 992×640 时，班级名单页适应窗口高度：班级列表和学生名单各自滚动，搜索、班级操作、表头和分页保持可见。其他页面的滚动方式不变。
- 每页默认 20 人，可选 50 / 100 人；序号与“第几位 / 共几位”帮助定位。搜索姓名或邮箱会查询当前班级的全部学生，不只查询当前页。
- 搜索或切换每页数量会回到第一页；显式切换班级也会清空搜索。编辑、删除保留搜索和页码，删除末页最后一人时回到有效页；添加、批量导入后清空搜索并回第一页。

- 快速切班时过期请求不会覆盖新班级；加载失败可重新加载，不会误显示上一班名单。
- 分页只是管理页的显示方式，不会改变班级数据或“写通知”的全班收件人。没有新增后端接口、数据库迁移或外部依赖。
- 更新后重新加载页面即可；CSS / JS 已使用新版本参数。没有必要为了此次前端改动重启正在发送邮件的服务。

## 10. 批量导入右侧抽屉（2026-10-18）

“班级名单 → 批量导入”使用右侧 720px 抽屉；小于 768px 的窗口全屏显示。顶部固定目标班级，底部固定按钮，中间滚动。其他编辑、删除与邮箱设置弹窗不变。

1. **录入名单**：选择“粘贴名单”或“上传文件”。两种输入在本次打开期间各自保留，但只发送当前选中的来源；支持 CSV / XLSX、最多 5 MB 和 5000 行。
2. **检查并导入**：查看检查摘要、识别列、预览结果；列设置默认折叠，无有效行且有非法行时自动展开。修改映射后必须重新检查。
3. 预览“全部 / 问题 / 重复”作用于全部结果，每页 50 行，不再截断到前 200 行。只有出现问题才展示跳过/覆盖选项，两项默认都不勾选；文件内部冲突不能通过覆盖已有姓名解决。
4. 有未提交内容时，关闭、取消、Escape 或点击遮罩均先在抽屉内确认放弃；不会叠加居中弹窗。真正关闭后不保存这些输入。
5. 确认期间不能重复提交或关闭。预览过期可重新检查；导入成功但刷新失败时只能重新读取名单。提交回包丢失、结果不确定时也不会自动重发导入请求，应先刷新核对。

### 本次遇到的本机 WMI 查询卡顿

本次 Python 3.12 在导入 Argon2 时，`platform.machine()` 的 WMI 查询出现挂起。未修改 Python 安装、依赖、项目后端或系统服务；验证进程和当次本机服务采用“让 Python 使用已有的非 WMI 回退”的进程内兼容方式。此状态属于环境快照，不代表每次都需要此方式。

若普通命令在导入阶段出现相同卡顿，可仅对当前验证进程使用：

```

```


## 11. 搜索并选择收件同学（2026-10-18）

在“写通知 → 选择收件同学”选择班级后，可以搜索姓名或邮箱。搜索栏、已选人数和批量选择留在列表上方，只有名单区域滚动。

- 搜索不区分大小写，忽略首尾空格，仅筛选显示，不改变勾选。右侧“已选 X / Y 人”是实际的全班选中人数，而不是当前搜索结果人数。
- 无关键词时，批量勾选为“选择全班同学”；有关键词时变为“选择搜索结果（N 人）”，只增加或移除匹配同学，其他已选人保留。半选状态同样以匹配结果为准。
- 搜索会显示匹配数及其中已选人数；如果还有隐藏的已选同学，会显示“另有 N 位已选同学不在搜索结果中”。清空搜索可重新看到完整名单。
- 切换班级仍默认全选新班级并清空搜索；打开草稿只恢复草稿保存的收件人，明确保存为空的名单不会变成全班。搜索关键词不写进草稿，也不会单独触发“未保存修改”提醒。
- 同班级名单刷新后保留搜索和仍然存在的已选同学；新增或导入的同学不会因此被自动勾选。下拉框人数与实际加载结果同步。
